\newcommand{\paperabstract}{Este trabajo desarrolla y evalúa un flujo reproducible para el pronóstico univariado de demanda eléctrica horaria mediante N-BEATS. Se utiliza la serie de Austria de Open Power System Data, procesada bajo el contrato \texttt{timestamp}/\texttt{y}, y se evalúan horizontes de 24, 168, 336 y 720 horas. El desempeño se compara con ARIMA mediante MAE, RMSE y MAPE sobre los mismos timestamps. Los resultados muestran que N-BEATS reduce el error en los horizontes semanal, bisemanal y mensual, mientras que en el horizonte diario ambos modelos presentan un desempeño comparable. Además, se implementa una aplicación de escritorio para preparar datos, entrenar modelos, conservar artefactos y generar pronósticos trazables.}
